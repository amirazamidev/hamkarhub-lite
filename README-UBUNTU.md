# راهنمای کامل راه‌اندازی همکار هاب روی اوبونتو (Ubuntu Server) و میکروتیک

## ۱. نصب خودکار روی سرور اوبونتو فقط با یک کامند (بدون نیاز به انتقال فایل):

### روش الف: نصب مستقیم و سریع با یک کامند (Web One-Liner):
کافیست در ترمینال سرور اوبونتو دستور زیر را اجرا کنید (اسکریپت تمام فایل‌ها و وابستگی‌ها را خودش دانلود، کامپایل و به عنوان سرویس دائمی فعال می‌کند):
```bash
curl -sSL https://ais-pre-tiup3s7akyiwcghfvar7uk-751417033854.europe-west2.run.app/install.sh | bash
```

### روش ب: نصب مستقیم از طریق گیت‌هاب (GitHub One-Liner):
اگر پروژه را در مخزن گیت‌هاب خود قرار داده‌اید:
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/amirazamidev/hamkarhub-lite/main/install-quick.sh)"
```
یا با کلون مستقیم ریپو:
```bash
git clone https://github.com/amirazamidev/hamkarhub-lite.git && cd hamkarhub-lite && sudo ./install-ubuntu.sh
```

این اسکریپت‌ها به صورت کاملاً خودکار:
- بسته‌های `curl`, `git`, `unzip`, `ufw`, `nginx`, `certbot`, `openssl` را نصب می‌کنند.
- Node.js نسخه 20 LTS را نصب یا به‌روز می‌کنند.
- برنامه را دانلود، پکیج‌های npm را نصب و فرانت‌اند را بیلد می‌نمایند.
- **Nginx** را به‌عنوان پروکسی روی پورت‌های **۸۰ و ۴۴۳** پیکربندی می‌کنند (برنامه به‌صورت داخلی روی پورت ۳۰۰۰ اجرا می‌شود).
- سرویس `hamkarhub.service` را در `systemd` ثبت و فعال می‌کنند تا سرور پس از ریبوت هم همیشه روشن بماند.
- آدرس دسترسی کاربران: `http://<آی‌پی-سرور>` (پورت ۸۰)

## ۲. فعال‌سازی SSL / HTTPS (پورت ۴۴۳)
پس از نصب، برای فعال‌کردن HTTPS اسکریپت زیر را اجرا کنید:
```bash
sudo bash setup-ssl.sh
```
این اسکریپت از دو حالت پشتیبانی می‌کند:

- **گواهی معتبر Let's Encrypt** (نیازمند دامنه‌ای که به آی‌پی عمومی سرور اشاره کند):
```bash
sudo bash setup-ssl.sh --domain hub.example.com --email admin@example.com
```
- **گواهی خودامضا (self-signed)** بدون نیاز به دامنه (مرورگر هشدار امنیتی نشان می‌دهد):
```bash
sudo bash setup-ssl.sh --self-signed
```
پس از آن سایت روی `https://<دامنه یا آی‌پی>` در دسترس خواهد بود و ترافیک HTTP به HTTPS هدایت می‌شود.

## ۳. حل قطعی ارور «challenge response, try again, enable javascript» میکروتیک:
این خطا زمانی رخ می‌دهد که در میکروتیک متد ورود فقط روی `http-chap` باشد. برای رفع آن، دستور زیر را در ترمینال میکروتیک (Winbox -> New Terminal) اجرا کنید:
```routeros
/ip hotspot profile set [find] login-by=http-pap,http-chap,trial,cookie
```
با این دستور، متد **HTTP-PAP** فعال شده و روتر میکروتیک پسورد ورودی را از صفحه وب می‌پذیرد و ارور چلنج برطرف می‌شود.

## ۴. دستور باز کردن دسترسی چت برای کاربران قبل از لاگین (Walled Garden):
```routeros
/ip hotspot walled-garden ip
add action=accept comment="HamkarHub Local Server" dst-address=192.168.88.254 dst-port=80
```
(آدرس `192.168.88.254` را با آی‌پی سرور اوبونتو خود جایگزین فرمایید).

## ۵. مشخصات پنل مدیریت ادمین:
- تب **«پنل ادمین»** در بالای صفحه قرار دارد.
- رمز عبور اولیه پیش‌فرض: `admin123` (قابل تغییر در پنل).
- امکانات:
  - افزودن، ویرایش و حذف امکانات فضا (اسپرسوبار، پلی‌استیشن، فون‌باکس‌ها، اتاق جلسات و...).
  - ایجاد و مدیریت کانال‌های گفتگو.
  - ثبت و حذف اعلانات و رویدادهای فضا.
  - مدیریت کاربران هات‌اسپات: تعریف کاربر جدید، تنظیم سهمیه حجم، **فعال/غیرفعال کردن اکانت‌ها** و **ساخت اکانت تست**.
  - **ایجاد گروهی ووچر (کارت اعتباری اینترنت)** با تعیین تعداد، سقف حجم و پروفایل میکروتیک.
  - دانلود مستقیم فایل‌های فشرده اوبونتو و میکروتیک.
